# 更新日志

## 1.0.1

- 按“在线”标签与站外标题链接的结构特征过滤 Bootstrap 结果卡片，修复老王广告更换域名后漏过的问题。

## 1.0.0

- 适配 SkrBT 新版以 `ul.list-unstyled` 呈现的搜索结果，恢复本页筛选、文件列表折叠、磁链打开与复制，以及自动缓存功能。
- 根据 SkrBT、老王页面样本过滤置顶的“在线”外站推广结果，包括 `2w0y6.com` 广告卡片。
- 忽略本地页面样本文件，并调整磁力猫、磁力狗操作行的缓存标记垂直对齐。
- 将网站分类重排为：第一类磁力猫、磁力狗 Zsky 资源站；第二类 Bootstrap 搜索站；第三类 BT4G。

## 0.9.5

- 统一脚本元数据与项目许可证为 MIT，并恢复公开 GitHub Issues 的 `@supportURL`。

## 0.9.1

- 抽取第一类和第二类网站共用的磁力缓存模块，统一 URL 去重、请求复用、失败清理、重试和成功提示。
- 增加绿色“已缓存磁力链接”状态，以及自动获取配置：每组并发数量、批次请求间隔和重试次数。
- 自动缓存默认每组处理 4 条，并采用新任务优先的批次队列。

## 0.8.1

- 增加全局“自动获取磁力链接”配置，并为支持的网站使用规范化详情 URL 作为缓存键。
- 兼容老王新版搜索结果结构，修正网站分类和自动获取适用范围。
- 增加按钮内嵌失败反馈，移除页面 `alert` 弹窗。

## 0.7.0

- 增加第一类网站，适配基于 Zsky 的 `clmclm.com` 和 `clgclg.com` 搜索页。
- 支持按需从详情页提取磁链，并提供打开与复制操作及 info hash 回退方案。

## 0.6.1

- 增加 BT4G 支持，包括详情页复制磁链、动态搜索结果监听和剪贴板降级方案。
- 为不同类型网站补充清晰的代码分区注释。

## 0.5.1

- 扩展 SkrBT、老王和 Lemon 等搜索域名支持，并将站点实现收敛为共享主机分组和统一配置。

## 0.4.5

- 建立脚本基础能力：广告与结果筛选、详情与文件列表操作、磁链打开和复制。
- 增加仓库元数据、更新地址和许可证声明，并简化脚本说明。
