# 更新日志

## 0.9.1

- 将自动缓存的默认并发数量从 3 条调整为每组 4 条。

## 0.9.0

- 将第一类和第三类网站的 URL 去重、Promise 缓存、失败清理及成功通知抽取为通用缓存模块。
- 为成功缓存的搜索结果增加绿色“已缓存磁力链接”状态提示。
- 增加自动缓存并发数量配置，默认同时处理 3 条。
- 增加批次请求间隔配置，默认每组间隔 1 秒。
- 增加失败重试次数配置，默认每条请求额外重试 3 次。
- 采用新任务优先的批次队列，失败任务排到队尾，且重试与新任务共享并发上限。

## 0.8.1

- 修正网站分类编号：同构 Bootstrap 镜像站为第一类，BT4G 为第二类。
- 兼容老王新版居中的 `.col-md-6` 结果容器，以及标题中的 `/detail/` 详情链接。
- 排除不包含站内详情链接的统计面板和广告面板。
- 将自动获取功能从第二类网站调整到第一类网站。
- 为第一类网站增加规范化 URL 缓存。

## 0.8.0

- 增加用户脚本全局“自动获取磁力链接”设置，可在支持的域名间共享。
- 自动获取最多同时发起 4 个请求，并显示处理进度和结果摘要。
- 将规范化详情 URL 作为 BT4G 和 Zsky 网站内存 Map 的唯一缓存键。
- 增加按钮内嵌失败反馈，并移除 Zsky 操作中的 `alert` 弹窗。

## 0.7.0

- 增加第三类网站，适配基于 Zsky 的 `clmclm.com` 和 `clgclg.com` 搜索页。
- 为资源卡片增加按需“打开磁链”和“复制磁链”操作。
- 支持从详情页预览配置提取磁链，并以 40 位 info hash 作为回退方案。

## 0.6.1

- 为每种受支持的页面类型增加清晰的代码分区注释。

## 0.6.0

- 将 BT4G 作为第二类支持的网站。
- 为 BT4G 搜索结果增加按需“打开”和“复制”操作。
- 为 BT4G 详情页增加明确的“复制磁链”按钮。
- 增加 BT4G 哈希链接和 URL 哈希磁链提取回退方案。
- 在有限时间内监听动态插入的 BT4G 搜索结果。
- 增加剪贴板降级方案，同时避免页面加载时自动复制。

## 0.5.1

- 将网站支持简化为共享主机分组和统一实现。
- 移除过早加入的单站选择器和功能定制。

## 0.5.0

- 增加对 SkrBT、老王和 Lemon 搜索域名的支持。
- 使用按站点配置的选择器和功能标记替代硬编码行为。
- 重命名用户脚本，以体现多网站支持。

## 0.4.5

- 简化用户脚本说明。

## 0.4.4

- 声明整个仓库采用 GPL-3.0-only 许可证。

## 0.4.3

- 增加仓库元数据和直接更新地址。
- 增加按需请求详情页并提取磁链的功能。
- 增加“打开”“复制”“查看详情”和文件列表折叠操作。
- 增加已知广告过滤和本页结果筛选功能。
