# 更新日志

## 1.0.16

- 重置默认角色后清空状态提示区域，避免显示冗余反馈。

## 1.0.15

- 配置面板选择角色后显示“已配置”，页面刷新并恢复已保存角色后也保持该状态。
- 在领取弹窗中手动改选角色时，自动移除已不对应当前选择的“已预填默认角色”提示。

## 1.0.14

- 将默认角色配置改为常驻面板，页面加载后自动读取角色信息；在原生领取弹窗中设为默认角色后会同步面板选择。
- 优化面板底部布局：状态提示保持单行并在空间不足时省略显示；将低频的刷新操作替换为“重置”，用于清除默认角色。
- 将面板调整为 300px 宽度，“重置”按钮固定为 56px。

## 1.0.10

- 恢复 `qu.sdo.com` 全域匹配，为后续商城页面功能扩展保留入口；当前领取预填功能仍仅在个人中心页面运行。

## 1.0.9

- 将当前领取预填功能限制为道具仓库个人中心页面及其子页面。

## 1.0.8

- 兼容商城当前直接以 `.el-dialog` 挂载的领取弹窗，使底部“设为默认领取角色”按钮正常显示。
- 默认角色预填失败或已不在可用角色列表时，在弹窗底部显示重新配置提示，且保留原有默认角色配置。

## 1.0.6

- 修正角色接口请求到错误域名而返回商城 HTML 的问题，改为请求商城服务接口。
- 按原生领取表单的实际结构，将配置改为“游戏大区 → 游戏角色”两级选择；服务器信息随所选角色保存。
- 修正默认角色预填流程，移除原生表单不存在的服务器组等待步骤。
- 将右下角“默认角色”入口上移至距底部 15% 视口高度的位置，减少与其他脚本入口的重叠。

## 1.0.5

- 将用户脚本元数据许可证更新为 MIT。

## 1.0.4

- 新增默认领取角色配置与道具仓库领取表单预填功能，且不自动确认或领取道具。
- 在商城原生领取弹窗底部增加“设为默认领取角色”按钮，仅保存当前手动选择的角色。
- 将脚本更名为“FF14 道具商城和仓库页面增强”，迁移目录、文件名和 Raw 更新地址。
- 增加公开 GitHub Issues 页面的 `@supportURL`。
