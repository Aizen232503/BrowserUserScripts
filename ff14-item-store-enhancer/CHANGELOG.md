# 更新日志

## 1.0.10

- 恢复 `qu.sdo.com` 全域匹配，为后续商城页面功能扩展保留入口；当前领取预填功能仍仅在个人中心页面运行。

## 1.0.9

- 右下角默认角色配置改为常驻面板，并在页面加载后自动读取角色信息。
- 在原生领取弹窗中设为默认角色后，自动同步右下角配置的已选大区和角色。
- 将当前领取预填功能限制为道具仓库个人中心页面及其子页面。

## 1.0.8

- 领取弹窗仅匹配当前商城使用的“选择收货游戏角色”对话框结构。
- 默认角色预填失败或已不在可用角色列表时，在弹窗底部显示重新配置提示，且保留原有默认角色配置。

## 1.0.7

- 兼容商城直接以 `.el-dialog` 挂载领取弹窗的结构，使弹窗底部“设为默认领取角色”按钮能正常显示。

## 1.0.6

- 修正角色接口请求到错误域名而返回商城 HTML 的问题，改为请求商城服务接口。
- 按原生领取表单的实际结构，将配置改为“游戏大区 → 游戏角色”两级选择；服务器信息随所选角色保存。
- 修正默认角色预填流程，移除原生表单不存在的服务器组等待步骤。
- 将右下角“默认角色”入口上移至距底部 15% 视口高度的位置，减少与其他脚本入口的重叠。

## 1.0.5

- 将用户脚本元数据许可证更新为 MIT。

## 1.0.4

- 增加指向公开 GitHub Issues 页面的 `@supportURL`。

## 1.0.3

- 脚本更名为“FF14 道具商城和仓库页面增强”，并迁移目录、文件名和 Raw 更新地址。

## 1.0.2

- 右下角配置入口和面板标题调整为“默认角色”。
- 角色配置改为“游戏大区 → 游戏服务器 → 游戏角色”三级下拉选择器。

## 1.0.1

- 在商城原生领取弹窗底部增加“设为默认领取角色”按钮。
- 该按钮仅保存当前已选择角色，不会确认或领取道具。

## 1.0.0

- 新增右下角折叠式默认领取角色配置面板。
- 支持读取商城账号已有的大区与角色并保存选择。
- 在道具仓库领取弹窗中预填大区、服务器和角色。
- 明确不自动确认或领取任何道具。
