# FF14 道具商城和仓库页面增强

为盛趣 FF14 道具商城和道具仓库领取弹窗预填常用领取角色的 Tampermonkey 用户脚本。

> 兼容性说明：仅在 Windows 与 Chromium 内核浏览器中测试；其他平台或浏览器内核尚未完成兼容性验证。

## 功能

- 在右下角常驻的“默认角色”面板中，通过“游戏大区 → 游戏角色”两级选择器读取当前账号可用角色；角色选项会显示所属服务器。
- 保存一个默认领取角色，显示格式为“`[服务器]角色名`”。
- 页面刷新后会自动恢复已保存的默认角色，并显示“已配置”状态。
- 在道具仓库打开领取弹窗时，自动填入已保存的大区、服务器和角色。
- 也可以在商城原生领取弹窗底部点击“设为默认领取角色”，直接保存当前手动选择的角色。
- 会通过商城本身的角色加载逻辑确认配置仍可用。
- 若默认角色已不存在或暂时无法加载，会在领取弹窗底部提示重新设置，并保留原配置供稍后重试。
- “重置”可移除已保存的默认领取角色，并立即重置配置面板。

## 安全边界

脚本只预填领取表单，不会点击“确认”、不会调用领取接口，也不会自动领取任何道具。最终领取仍需由你在商城页面手动确认。

角色信息仅保存于用户脚本管理器的本地存储。

## 支持页面

- `https://qu.sdo.com/*`
- 当前角色预填仅在商城个人中心的“道具仓库”领取弹窗中生效；全域匹配为后续商城页面功能预留。

## 安装方法

在安装 Tampermonkey 后，打开 [Greasy Fork 脚本页面](https://greasyfork.org/zh-CN/scripts/591470)，点击“安装此脚本”即可。
