# 更新日志

## 1.2.6

- 将用户脚本元数据许可证更新为 MIT。

## 1.2.5

- 恢复指向公开 GitHub Issues 页面的 `@supportURL`。

## 1.2.3

- 恢复右下角的折叠式设置入口，避免在 iframe 登录页中遮挡表单。
- 保留 1.2.2 的分段式登录方式按钮样式。

## 1.2.2

- 将默认登录方式的单选项优化为带选中状态的分段按钮，提升辨识度与交互反馈。

## 1.2.1

- 默认登录方式增加“二维码”选项。
- 将默认登录方式改为三个单选项，选择后立即保存并切换。
- 默认账号改为按 Enter 后保存并立即应用。
- 参照磁力脚本，将设置面板固定显示在页面右下角。

## 1.2.0

- 增加默认登录方式设置，可选择密码登录或一键登录。
- 增加默认账号设置，并在两种登录方式间共用。
- 增加登录页内的轻量设置面板，两个配置项始终同时显示。
- 使用用户脚本本地存储持久保存设置。

## 1.1.3

- 适配新版盛趣登录页使用的 `LoginFrameFC.php` 登录表单。

## 1.1.2

- 更新脚本版本号。

## 1.1.1

- 移除指向私有 GitHub Issues 页面的 `@supportURL`。

## 1.1.0

- 移除恢复 FF14 充值账号输入框的功能。
- 移除盛趣充值页面的匹配规则和页面路由逻辑。
- 脚本现仅负责自动勾选盛趣登录协议。
- 更新脚本名称、说明和项目文档。

## 1.0.1

- 简化用户脚本说明。

## 1.0.0

- 合并 FF14 充值页面和盛趣登录页面增强功能。
- 增加按主机名分发功能的逻辑，确保每项功能只在对应页面运行。
- 增加仓库元数据、直接更新地址和 GPL-3.0-only 许可证声明。
