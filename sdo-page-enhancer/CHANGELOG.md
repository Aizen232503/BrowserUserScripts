# 更新日志

## 1.2.8

- 恢复在 `LoginFrameFC.php` 和旧版登录 iframe 内显示折叠式配置入口，修复外层 `LoginSDO.php` 下增强生效但配置入口缺失的问题。

## 1.2.7

- 将协议接受设为默认登录方式切换的前置条件；协议复选框尚未出现或未成功接受时，等待后续重试再切换。

## 1.2.6

- 统一脚本元数据与项目许可证为 MIT，并恢复公开 GitHub Issues 的 `@supportURL`。

## 1.2.3

- 将默认登录方式优化为带选中状态的分段按钮。
- 恢复右下角折叠式设置入口，避免在 iframe 登录页中遮挡表单。

## 1.2.1

- 增加默认登录方式和默认账号设置，登录方式支持密码登录、一键登录和二维码。
- 默认登录方式会立即保存并切换；默认账号按 Enter 后保存并立即应用。
- 使用用户脚本本地存储持久化配置，并在登录页右下角提供设置面板。

## 1.1.3

- 适配新版盛趣登录页使用的 `LoginFrameFC.php` 登录表单。

## 1.1.0

- 移除已失效的 FF14 充值账号输入和充值页面逻辑，脚本收敛为盛趣登录协议自动勾选与登录页增强。

## 1.0.1

- 建立盛趣页面增强脚本，增加按主机名分发功能、仓库元数据和更新地址。
